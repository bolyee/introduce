# 공개 전 편집 메모 — 배포 대상 아님

사실관계 기준: 기존 2번 CV(현재 `../../02_CV_Choi_Jungwoo/cv.tex`), 해당 CV 폴더의 `archive/`에 보관한 첨부 `cv_이현중.pdf` 및 사용자 요청. PDF와 최신 LaTeX의 구성·표현은 일부 다르므로 최신 LaTeX와 사용자의 명시적 지침을 우선했다. 원본 파일은 수정하지 않았다.

## 자동 믹싱의 현재 구현 범위
- EQ / Compressor / Reverb별 실제 구현, 최적화 대상 파라미터와 범위 확인.
- 특히 Reverb가 자동 최적화되는지, 고정 처리인지 확인.
- 사이트와 공개용 CV에는 확인 전까지 이펙트별 자동 최적화를 단정하지 않고 '레퍼런스 기반 오디오 이펙트 파라미터 최적화 파이프라인'으로 설명.
- 정량 성능, 실시간 처리 여부, 현재 진행 상태 및 프로젝트 기간은 확인 전 추가하지 않음.
- Saturation과 지각적 특성의 관계는 후속 관심이며 구현 결과가 아님.

## 프로젝트 코드 링크
- 세 프로젝트 각각의 공개 저장소 URL 및 README 필요.
- 공동 작업 여부, 공개 가능한 본인 코드 범위 확인. 제공 전에는 저장소 버튼을 표시하지 않음.
- 모델명, 데이터 출처·규모, 정확도는 제공되지 않아 추가하지 않음.

## 실제 음원 및 공연 링크
- 2025년 발매 곡명, 앨범명, 공개 발매 URL, 커버 이미지와 사용 권한.
- 공연 영상 URL, 공연 시점, 영상 및 음원 공개 권한.
- 외주 믹싱 음원은 의뢰인과 권리자의 공개 동의가 확인된 경우에만 추가.

## 공개 가능한 데모 자료
- 자동 믹싱: 입력 / 레퍼런스 / 처리 결과 파일, 각 자료의 공개 권한.
- 비교 자료의 동일 구간, 음량 조건, 처리 설정 및 해석 가능한 설명.
- 회사 관련 평가 프로그램 화면이나 데이터는 공개 허용 범위 확인 후 추가.
- `approved: true`인 자료만 빌드에 포함. 승인되지 않은 파일 자체를 site/에 넣지 말 것.

## 공개용 CV
- 첨부 원본 PDF는 전화번호, 근거 미확인 최상급 표현, 이펙트 범위 단정을 포함하므로 그대로 배포하지 않음.
- `cv.tex`에서 파생한 `cv-public.tex`로 공개용 PDF를 재생성해 실제 링크로 연결함.
- 제거: 전화번호, '세계 최초' 문장. 완화: 이펙트별 파라미터 최적화 설명. 표기 통일: 전자IT미디어공학과.
- 원본 PDF와 공개용 PDF가 다르다는 점을 최종 검토 시 확인.
- '현재'로 표시된 학년·학부연구생·인턴 상태, 성적 및 졸업 예정일은 발송 직전 재확인.

## 현재 보관 상태

위 공개용 CV 제작 기록은 과거 작업 이력입니다. 현재 웹페이지에서는 CV 링크가 제거되어 있으며, 이 폴더의 TeX·PDF는 보관용 사본으로 유지합니다. 지원용 CV나 웹페이지와 자동 동기화되지 않습니다.
