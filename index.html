About

서울과학기술대학교 전자IT미디어공학과 4학년 이현중입니다. 중학생 시기부터 작곡을 시작했고, “프로의 사운드와 내 사운드는 왜 다른가?”라는 질문을 계기로 믹싱과 마스터링에 관심을 갖게 되었습니다. 원하는 소리를 구현하는 과정에서 신호처리 원리와 사람이 소리를 지각하는 방식에도 흥미를 느꼈습니다.

전자공학을 공부하며 음향 기술의 기반이 되는 신호처리 지식을 쌓았습니다. 음향 전문기업 A49에서 음향기기 평가 프로그램과 제품 개발에 참여하고, 믹싱·마스터링 외주 작업과 단독 프로듀싱을 통한 음원 발매도 이어가고 있습니다. 학부 연구생으로서는 레퍼런스 곡 기반 자동 믹싱 시스템을 구현하며 음악 작업에서 경험한 문제를 신호처리와 AI로 다루었습니다.

앞으로는 음악 제작 과정에서 쌓은 경험과 공학적 지식을 바탕으로, 음악 및 오디오 신호처리에 AI를 접목하는 연구를 하고 싶습니다.

Projects

AutoMix · 레퍼런스 곡 기반 자동 믹싱 시스템

미분 가능한 EQ·Compressor·Reverb 체인을 구성하고, 레퍼런스 곡과 입력 오디오 간 차이를 손실 함수로 정의해 이펙트 파라미터를 최적화하는 파이프라인을 구현했습니다.

파이프라인 구현

자세히 보기: AutoMix · 레퍼런스 곡 기반 자동 믹싱 시스템
  • 문제의식. DDSP(Differentiable DSP)의 “모델이 사전에 정의된 노브를 돌린다”는 관점을 실제 믹싱 워크플로우에 적용해, 레퍼런스 곡을 기준으로 믹싱을 자동화하고자 했습니다.
  • 설계 및 구현. 미분 가능한 EQ·Compressor·Reverb 체인을 구성했습니다. 레퍼런스 곡과 입력 간 차이를 손실 함수로 정의하고, 이펙트 파라미터를 최적화하는 파이프라인을 구현했습니다.

AI 생성 음악 판별

사전학습 모델을 사용하고 최신 생성 음악 데이터로 파인튜닝했습니다. GPU 서버의 Docker 환경을 구성하며 학습·분류 과정을 경험했습니다.

공개 데이터셋 부족 등으로 중단. 최신 생성 음악에 대한 일반화 한계 확인.

자세히 보기: AI 생성 음악 판별
  • 문제의식. 새로운 생성 음악에도 기존 판별 모델이 대응할 수 있는지 확인하고자 했습니다.
  • 수행 내용과 역할. 사전학습 모델 사용과 최신 생성 음악 데이터에 대한 파인튜닝을 진행했습니다. 연구실 GPU 서버에 Docker 환경을 구성하고 의존성 문제를 해결하며 학습과 분류 과정을 경험했습니다.
  • 현재 결과와 한계. 기존 모델의 최신 생성 음악 대응 한계를 확인했습니다. 공개 데이터셋 부족 등의 이유로 프로젝트를 중단했으며, 데이터 확보가 모델의 일반화 가능성을 검토하는 데 중요함을 배웠습니다.
  • 후속 관심. 데이터 확보와 일반화 문제를 중심으로 다시 연구하고 싶은 주제입니다.

급수음 기반 실시간 컵 수위 추정

마이크로 수집한 급수음으로 컵 수위를 실시간 추정하는 모델과 ESP32 기반 급수 제어 파이프라인을 구현했습니다.

컵 사전 등록의 제약을 확인하고 대안 센서의 효율성을 고려해 주제 전환.

자세히 보기: 급수음 기반 실시간 컵 수위 추정
  • 문제의식. 정수기를 사용할 때 출수 과정을 계속 지켜봐야 하는 불편을 줄이고자 했습니다.
  • 수행 내용과 역할. 급수음을 마이크로 수집하고 컵 수위를 실시간 추정하는 모델을 구현했습니다. 급수를 제어하는 파이프라인은 ESP32로 구성했습니다.
  • 현재 결과와 한계. 정확한 수위를 예측하려면 컵을 사전 등록해야 한다는 제약을 확인했습니다. 동일한 제약 조건이라면 초음파 센서, 무게 센서 또는 용량 사전 입력 방식이 더 효율적일 수 있다고 판단해 주제를 전환했습니다. 이는 대안 기술의 성능을 실험으로 입증한 결과가 아닌, 사용 조건에 따른 판단입니다.
  • 배운 점과 후속 관점. 소리로 추정할 수 있는가와 실제 사용에 적절한가는 서로 다른 질문임을 경험했습니다. 문제 해결 방식을 정할 때 센서와 사용 조건을 함께 비교하는 관점으로 이어졌습니다.
